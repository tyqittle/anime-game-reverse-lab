# 星烬计划 / Project Ember — 可运行的动作游戏重构验证器

无需安装、无需联网，也不需要运行 Python。**双击 `web/index.html` 即可启动**，或在仓库主页使用 GitHub Pages 的 `index.html` 跳转。

### 操作

- A / D 或方向键：移动
- 空格：二段跳
- J：连击剑术（连按可增加段数）
- K 或 Shift：快速闪避（短暂无敌，冷却时间）
- L：远程飞刃
- P：暂停；R：重新开始
- 顶部「导入角色 PNG」：只读导入自己的 PNG/WebP 角色图，替换显示；数据仅存在当前浏览器内存，不会上传，也不会修改原文件
- 移动设备可使用屏幕虚拟按钮

### 实现

| 模块 | 文件 | 可替换部分 |
|---|---|---|
| 状态/物理/命中判定/敌人/Boss/掉落与通关 | `js/engine.js` | 独立玩法规则与画面实现 |
| 关卡/平台/敌人出生/危险区域/胜利目标 | `js/levels.js` | 独立数据 |
| 合成提示音 | `js/audio.js` | 可替换为获许可 WAV/OGG |
| 按键/移动端/本地素材导入/HUD | `js/app.js` | UI/输入适配 |
| 主题视觉 | `styles.css` | 响应式设计 |

### 当前限制

原创规则与关卡，**不是原神、鸣潮、忍者必须死3 等商业游戏的可运行逆向版本**，也没有导出其源码或客户端素材。首个关卡是可玩技术纵切片，暂时只有一个 Boss、一类关卡流程，关卡编辑器和资产流水线尚待后续迭代。源码图形为自绘 Canvas，玩家导入图不包含碰撞盒自动拟合和骨骼动画。
