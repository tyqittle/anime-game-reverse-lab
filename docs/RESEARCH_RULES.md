# 合法与安全的研究边界

1. 仅分析自身有权访问与研究的本地资源，遵守适用法律、合同及软件许可。
2. 本仓库不提供游戏原版安装包、角色立绘、音频、受版权保护的导出物、闭源源码、密钥、账号凭据。
3. 不提供 DRM 破解、绕过登录验证、反作弊规避、游戏服务器攻击、付费绕过、作弊服务或未经授权的联网操作。
4. 上传 issue / PR 前删除日志里的完整本机路径、用户信息、Token、IP、账号及非公开内容。
5. 示例必须为自制、明确授权或公共领域测试数据。逆向发现要注明版本、证据链与不确定性。
6. Git 忽略规则是最后一道保护而不是免责。上传前仍需 `git status` 与 `git diff --cached --stat` 审核。
