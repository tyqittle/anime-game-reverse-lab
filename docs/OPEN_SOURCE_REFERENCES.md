这里列出的四个工程已通过 **Git 子模块实际接入源码**，固定版本见 [UPSTREAM_INTEGRATION.md](UPSTREAM_INTEGRATION.md)，而非仅参考了它们的设计。

- UnityPy — https://github.com/K0lb3/UnityPy — MIT；`src/erlab/unity_assets.py` 实际调用。
- Grasscutter — https://github.com/Grasscutters/Grasscutter — AGPL-3.0；已有服务端重实现，独立源码子模块。
- LunarCore — https://github.com/Melledy/LunarCore — AGPL-3.0；已有服务端重实现，独立源码子模块。
- Godot Demo Projects — https://github.com/godotengine/godot-demo-projects — MIT、个别素材另外授权；实际已有的平台动作/JRPG 开源游戏工程。

商业游戏数据不包含在仓库。此前 `web/` 自写小游戏不再算作现有开源项目成果。
